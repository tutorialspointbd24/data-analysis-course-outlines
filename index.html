লাইভ ক্লাস — Power BI

সপ্তাহ ১

Power BI বেসিক এবং ডেটা প্রিপারেশন

লক্ষ্য

Power BI ইন্টারফেস এবং ডেটা হ্যান্ডলিং শিখা।

মূল বিষয়
  • Power BI Desktop এবং Service পরিচয়
  • বিভিন্ন উৎস থেকে ডেটা ইমপোর্ট
  • Query Editor দিয়ে ডেটা ট্রান্সফর্মেশন
  • ডেটা ক্লিনিং (Remove Duplicates, Change Data Types)
  • ব্যবহারিক প্রকল্প: সেলস ডেটা
সপ্তাহ ২

DAX এবং ডেটা ভিজ্যুয়ালাইজেশন

লক্ষ্য

DAX মধ্যম লেভেল এবং ভিজ্যুয়ালাইজেশন দক্ষতা বাড়ানো।

মূল বিষয়
  • FILTER, CALCULATE, ALL, RELATED ফাংশন
  • Time Intelligence Functions (YEAR, MONTH, DATEADD)
  • বিভিন্ন টাইপের চার্ট (Bar, Line, Pie, Matrix)
  • ভিজ্যুয়াল কাস্টমাইজেশন এবং Formatting
  • প্রকল্প: Monthly Sales Trend ড্যাশবোর্ড
সপ্তাহ ৩

Advanced DAX এবং ডেটা মডেলিং

লক্ষ্য

অ্যাডভান্সড DAX এবং ডেটা মডেলিং দক্ষতা বাড়ানো।

মূল বিষয়
  • Iterator Functions (SUMX, AVERAGEX, MAXX, MINX)
  • Context Transition (Row Context এবং Filter Context)
  • Star Schema এবং Snowflake Schema
  • Measures vs Calculated Columns
  • প্রকল্প: E-commerce Advanced DAX
সপ্তাহ ৪

Power BI Service এবং রিয়েল-ওয়ার্ল্ড প্রজেক্ট

লক্ষ্য

Power BI Service দিয়ে ড্যাশবোর্ড পাবলিশ ও সম্পূর্ণ প্রজেক্ট করা।

মূল বিষয়
  • Power BI Service রিপোর্ট পাবলিশ করা
  • Workspaces এবং Apps তৈরি
  • Row-Level Security (RLS) সেটআপ
  • Scheduled Refresh এবং Gateway সেটআপ
  • প্রজেক্ট: সম্পূর্ণ বিজনেস ড্যাশবোর্ড

লাইভ ক্লাস — SQL

সপ্তাহ ১

SQL বেসিক এবং ডেটা কোয়েরি

লক্ষ্য

SQL এর মৌলিক ধারণা এবং বেসিক কোয়েরি শিখা।

মূল বিষয়
  • SQL কী এবং RDBMS পরিচয়
  • SELECT, WHERE, ORDER BY ব্যবহার
  • DISTINCT দিয়ে অনন্য মান প্রদর্শন
  • INSERT, UPDATE, DELETE ডেটা ম্যানিপুলেশন
  • ব্যবহারিক প্রকল্প: Employee টেবিল
সপ্তাহ ২

Aggregation এবং ফাংশন

লক্ষ্য

Aggregation ও ফাংশন দিয়ে ডেটা অ্যানালাইসিস করা।

মূল বিষয়
  • COUNT, SUM, AVG, MIN, MAX ফাংশন
  • GROUP BY এবং HAVING ক্লজ
  • CONCAT, SUBSTRING, LENGTH ফাংশন
  • DATE, NOW, YEAR, MONTH ফাংশন
  • ব্যবহারিক প্রকল্প: সেলস ডেটা বিশ্লেষণ
সপ্তাহ ৩

Joins এবং Subqueries

লক্ষ্য

জয়েন ও সাবকোয়েরি দিয়ে জটিল ডেটা অ্যানালাইসিস করা।

মূল বিষয়
  • INNER, LEFT, RIGHT, FULL OUTER JOIN
  • Self Join এবং Cross Join
  • Scalar Subquery এবং Correlated Subquery
  • VIEW তৈরি এবং ব্যবহার
  • ব্যবহারিক প্রকল্প: E-commerce ডেটা
সপ্তাহ ৪

Advanced Topics এবং Real-World Project

লক্ষ্য

অ্যাডভান্সড টপিক শিখা এবং রিয়েল-ওয়ার্ল্ড প্রজেক্ট করা।

মূল বিষয়
  • Window Functions (ROW_NUMBER, RANK)
  • Common Table Expressions (CTE)
  • Pivot এবং Unpivot
  • Normalization (1NF, 2NF, 3NF)
  • প্রজেক্ট: Inventory Management System
